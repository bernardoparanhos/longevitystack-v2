# LongevityStack

**The engineering of sleep — evidence-based sleep thermoregulation.**

Sleep is a heat-transfer problem before it is a discipline problem: core body temperature has to drop for the body to enter deep sleep, and everything on this site follows from that physical principle.

## About

LongevityStack is a static site built with Astro 6 and deployed on Cloudflare Pages — no server, no UI framework. Content is written in MDX and organized into content collections validated with Zod schemas.

## Structure

- **Understand** — the physical mechanism: why the body loses heat to fall asleep, and how sleep architecture breaks.
- **Protocols** — ordered, timed steps derived directly from the mechanism.
- **Compounds** — supplements that affect thermoregulation or sleep architecture, evidence-graded.
- **Gear** — hardware that controls the sleep environment, reviewed and verdicted.
- **Field Notes** — N=1 experiments run by the author, with raw data.
- **Tools** — interactive calculators and simulators to run the model yourself.
